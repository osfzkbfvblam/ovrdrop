## 🕹️ Overview

OVRdrop lets you place any desktop application, browser window, or webcam feed as an in-world overlay inside any SteamVR game without leaving VR.

Whether you're a newcomer or a veteran, OVRdrop provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Window Capture** | Overlay any visible desktop window directly in VR space |
| **Webcam Overlay** | Display a live webcam feed inside your VR environment |
| **In-World or Overlay** | Attach overlays to the world, your hand, or the headset |
| **Opacity Control** | Adjust transparency to keep overlays unobtrusive |
